JumpDAO는 현실 공간에 디지털 보물을 숨기고 사람의 이동을 경제로 연결하는 위치기반 Web3 플랫폼입니다.
게임화된 탐험, 디지털 자산 경제, 온·오프라인 보상 시스템으로 사람의 발걸음이 곧 지역 상권의 매출이자 플랫폼의 가치가 됩니다.

Core Vision

광고를 '보는' 시대에서
보물을 찾기 위해 '움직이는' 시대로

기존 플랫폼은 사람의 시선(Attention)을 얻기 위해 스크린 안에서 경쟁합니다.
JumpDAO는 사람이 직접 특정 장소로 이동(Movement)하게 만드는 새로운 경제 구조를 제시합니다.

Ecosystem

생태계 참여자 모델

JumpDAO는 유저 한 명만을 위한 플랫폼이 아닙니다. 모두가 기여하고, 모두가 수익을 나눕니다.

🏪 지역 가맹점 (Merchant)
  • 호텔, 식당, 카페, 관광지 등 실제 사업자 파트너
  • 매장 내 QR/NFC 보물 배치로 방문 유저 보장
  • 플랫폼 결제는 HEX로 즉시 처리 — 별도 정산 없음
  • 가맹점 이용 시 유저에게 잭팟·아이템·추가 게임코인 지급
👥 추천인 시스템 (Referral)
  • 개인 QR 코드로 신규 가입 시 즉시 1,000 게임코인 지급
  • 추천인은 피추천인의 상품 구매·결제·가맹점 소비 시 자동 수익 분배
  • 프로토콜 차원의 자동 실행 — 별도 청구 불필요
🌍 지역 에이전트 (Regional Agent)
  • 특정 행정구역의 보물 경제와 이벤트 총괄
  • 관할 구역 상점 매출의 50% 수익 쉐어
  • 모집 유저 플랫폼 활동 수수료 (추천 수익)
  • 유치 가맹점 매출 일부 + 지자체 연계 관광 이벤트 수익
Tokenomics & Reward

수익 배분 & 금융 모델

📊
거버넌스 스테이킹

JUMP 토큰 스테이킹으로 매주 HEX 형태의 배당금 수령. 배당 재원: 플랫폼 수수료 + 가맹점 결제 + 정회원 회비 + 바우처 매출 + 정회원 전용몰 + B2B 광고.

추가 혜택: 관광·호텔·여행 VIP 바우처, 스톡옵션 우선 구매권

📜
스마트 컨트랙트 스톡옵션

장기 스테이킹 유저·핵심 에이전트에게 스톡옵션 바우처 제공. 만기 시 약정된 락인 가격으로 JUMP 토큰 매수 권리가 자동 실행.

만기 전 P2P 거래 및 양도 가능 — 권리는 최종 보유자에게 귀속

핵심 구조: "플랫폼 성장에 기여한 사람이 플랫폼의 미래 가치도 함께 가진다."

Technical Architecture

기술 아키텍처

대규모 실시간 위치 데이터와 Web3 토큰 경제의 신뢰성을 보장하는 고성능 하이브리드 아키텍처.

📡
Anti-Spoofing GPS 검증

보물 획득·상점 접근·전투 시 서버(Cloud Functions)에서 이중 좌표 검증 알고리즘 수행. 위치 우회(Faking) 원천 차단.

🔒
Web2-Friendly 수탁 지갑

opBNB Mainnet + ethers.js v6. 개인키 AES-256-GCM 암호화 서버 보관. 가스비 대납 스마트 컨트랙트로 시드구문 없이 사용 가능.

🗺️
실시간 지도 렌더링

Google Maps + Canvas 오버레이. 수천 개의 몬스터·보물박스·NPC를 부드럽게 렌더링. IntersectionObserver + 트로틀링으로 클라이언트 부하 최소화.

⚡
실시간 배틀 WebSocket

Railway Node.js WebSocket 서버로 전투·이동 데이터를 초저지연 처리. PostgreSQL 분리로 대규모 트래픽 비용 절감.

🔥
Firebase 인프라

Firestore + Firebase Auth + Cloud Functions v2. 실시간 배틀 로그는 분리된 WebSocket 서버 처리로 트래픽 비용 최적화.

📷
웹 기반 AR 모듈

앱 설치 없이 getUserMedia + DeviceOrientation으로 카메라 화면 속 현실 공간에 3D 보물상자를 정확하게 오버레이 렌더링.

사람의 이동이
디지털 자산 가치가 되는 세상

🚶 유저 📢 광고주 🏪 가맹점 🌍 지역 에이전트 💰 스테이킹 참여자

JumpDAO는 특정 기업이나 운영자만 이익을 얻는 구조가 아닙니다.
생태계 참여자 모두가 성장에 직접 참여하고, 그 결과를 함께 공유하는 DAO(탈중앙화 자율조직)를 지향합니다.

현실의 가치를 디지털 자산으로 증명하는 세상.
JumpDAO가 새로운 이동의 경제를 시작합니다.

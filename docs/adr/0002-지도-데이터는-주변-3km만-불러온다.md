# 0002. 지도 데이터는 플레이어 주변 3km만 불러온다

- 상태: 결정됨
- 날짜: 2026-10-20

## 배경
게임 시작 시 장소·보물상자·몬스터 HP·상점·가맹점을 위치와 관계없이 전 세계 분량으로 모두 불러왔다(관리자는 몬스터 203마리 전체). 데이터가 늘수록 첫 화면이 늦어지고 DB 읽기 비용이 늘어난다. 또 보물상자는 좌표가 글자로, 장소는 구글 지도 링크로만 저장된 경우가 있어 DB에서 거리로 걸러 받을 수 없었다.

## 결정
- 지도 데이터는 플레이어 위치 반경 3km만 불러오고, 1km 이상 움직이면 새 위치를 중심으로 다시 불러온다.
- 장소와 보물상자에 숫자 좌표와 위치 칸 값(geohash)을 일괄로 채워 넣는다. 새로 등록하는 데이터에도 자동으로 채운다. 이 위치 칸 방식은 주변 플레이어 표시에 이미 쓰고 있다.
- 반경 밖으로 벗어난 것은 화면에서 지운다. 단, 싸우고 있는 몬스터와 열고 있는 보물상자는 끝날 때까지 남긴다.
- 관리자도 평소에는 반경만 보고, "전 세계 보기" 버튼을 눌렀을 때만 전체를 불러온다.
- 가맹점 목록과 검색은 전체를 유지하고, 지도 표시만 반경을 적용한다.
- 위치가 없는 목록(보물 아이템·바우처)은 휴대폰에 저장해 두고, 관리자가 바꿨을 때만 새로 받는다.
- 서버 몬스터는 게임 서버 코드를 고칠 때 따로 적용한다(이번 범위 밖).

## 고려한 다른 방법
- 전체를 한 번 받아 휴대폰에 저장해 두기: 데이터 보정은 필요 없지만, 첫 진입과 데이터가 늘 때마다 여전히 전체를 받는다.
- 위도만 범위로 걸러 받기: 보정이 적게 들지만, 같은 위도대(전 세계 띠 모양)의 데이터를 모두 받게 된다.

## 영향
- 일괄 보정은 운영 DB를 바꾸는 일이므로 백업 → 건수 보고 → 승인 후 실행한다.
- 관리자가 좌표를 등록하는 화면이 위치 칸 값을 함께 저장해야 한다. 빠지면 그 데이터는 지도에 나오지 않는다.

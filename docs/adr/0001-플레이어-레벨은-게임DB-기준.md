# 0001. 플레이어 레벨은 게임 DB 기준으로 한다

- 상태: 결정됨
- 날짜: 2026-10-20

## 배경
게임 시작 시 플레이어 레벨·경험치를 웹3 서버 기능(`getMyOnChain`)에서 먼저 받고, 실패하면 게임 DB(`battle_players`)를 쓰고 있었다. 웹3 기능은 화면에서 모두 숨기기로 했고, 시작할 때마다 서버를 한 번 더 호출해 첫 화면이 늦어졌다.

## 결정
플레이어 레벨·경험치는 게임 DB(`battle_players`)만 기준으로 한다. 게임 시작 시 웹3 조회는 하지 않는다.

## 고려한 다른 방법
- 웹3 값을 계속 우선 사용: 숨긴 기능에 시작 속도가 묶이고, 웹3 서버가 느리거나 실패하면 레벨이 흔들린다.
- 웹3 값을 백그라운드에서 나중에 맞추기: 두 기준이 계속 공존해 혼란이 남는다.

## 영향
- 두 값이 다른 회원은 바꾸기 전에 확인하고, 필요하면 게임 DB 쪽을 한 번 보정한다(운영 DB 변경이므로 별도 승인).
- 나중에 웹3를 다시 켜더라도 레벨의 기준은 게임 DB이며, 웹3는 기록용으로만 쓴다.

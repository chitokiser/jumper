# [BestClub 공식 가맹점 홈페이지 개발·연동 마스터 가이드]
*(Merchant Channel Development & BestClub Database Integration Guide)*

> **문서 목적:**  
> 본 가이드는 **공식 가맹점 독립 홈페이지/쇼핑몰(예: BEST WINNER, 대한김치, 백제갈비 등)**을 개발하는 엔지니어 및 AI 에이전트가 **BestClub(`jumper-b15aa`) 중앙 데이터베이스 및 인프라**와 100% 실시간 연동하여, **가맹점 판매상품·웹메거진·프로필·회원 지갑·쿠폰 데이터를 가져와 홈페이지에 정확하게 표출**하도록 명시하는 **공식 단일 개발 가이드라인(Master Single Source of Truth)**입니다.

## 1. 최우선 원칙: "모든 DB는 BESTCLUB에서 가져온다"

가맹점 홈페이지는 자체적인 별도의 분리된 데이터베이스(로컬 DB, 독립 백엔드 서버 DB, 정적 JSON)를 구축하지 않으며, **모든 회원, 상품, 주문, 결제, 쿠폰, 웹진 데이터를 BestClub 중앙 Firebase(`jumper-b15aa`)에서 직접 실시간 연동**합니다.

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        BestClubVN 중앙 플랫폼                          │
│          (Firebase Auth / Firestore DB / Cloud Functions)              │

└──────────────────┬─────────────────────────────────┬───────────────────┘
                   │                                 │
                   ▼                                 ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────┐

└──────────────────────────────────────┘  └──────────────────────────────┘
```

## 3. 세부 데이터 소스 및 화면 표출 가이드

### 3.1 판매상품 (On-Sale Products & Menu)
* **데이터 출처 (DB):** BestClub Firestore `merchant_products` 컬렉션
* **쿼리 조건:**
  ```javascript
  where("merchant_id", "==", MY_MERCHANT_ID),
  where("sale_status", "==", "published")
  ```
* **표출 내용 및 UI 구성:**
  1. **카테고리 탭 분류:**
     * `ALL`: 전체 상품
     * `menu`: 식당 메뉴, 음식, 음료, 디저트
     * `physical_product`: 배송 상품, 김치, 밀키트, 식자재, 공산품
     * `service`: 시공, 수리, 청소, 인테리어, 전문 서비스
     * `booking`: 테이블 예약, 시설 대여, 상담 예약
  2. **상품 카드 구성요소:**
     * 대표 썸네일 이미지 (`images[0]`)
     * 상품명 (`product_name`) 및 간단 설명 (`description`)
     * 판매 가격: **`price` VND (BM)** 표기 (1 BM = 1 VND)
     * 재고 상태: `inventory > 0` (정상 판매) vs `sold_out` (품절 표시)
     * 버튼: `[🛒 장바구니]` 및 `[💎 BM으로 바로구매]`
  3. **상품 상세 모달:**
     * 다중 이미지 갤러리 (`images[]`)
     * 옵션 선택기 (`options[]`: 사이즈, 중량, 추가 구성품 및 추가 BM 금액)
     * 수량 선택기 및 실시간 총 결제 BM 계산
     * 배송 정보 및 이용 안내

### 3.2 웹메거진 / 베스트 매거진 (Web Magazine / Webzine)
* **데이터 출처 (DB):** BestClub Firestore `webzine_articles` 컬렉션
* **쿼리 조건:**
  ```javascript
  where("status", "==", "published")
  // 해당 가맹점 관련 기사(merchantId == MY_MERCHANT_ID) 최우선 정렬 노출
  ```
* **표출 내용 및 UI 구성:**
  1. **가맹점 메인 홈 섹션 (웹진 프리뷰 그리드):**
     * 최신 추천 기사 3~4개를 반응형 카드 형태로 배치
     * 기사 썸네일, 카테고리 뱃지(BUSINESS, LIFE, TODAY, HANOI 등)
     * 기사 제목, 요약문, 발행일, 조회수
  2. **매거진 전용 뷰어/페이지 (`/megazine`):**
     * 가맹점 스토리, 베트남 현지 뉴스, 생활/비즈니스 트렌드 탐색
  3. **기사 상세 모달 / 페이지:**
     * 고해상도 대표 이미지 및 본문 리치 텍스트
     * **기사 하단 가맹점 혜택 배너 (핵심):**
       * "본 기사는 **{가맹점명}**과 함께합니다. 매장 방문 결제 시 **결제액의 5% 캐시백 + 100,000 VND당 1 BT 지급!**"
       * 가맹점 결제 QR 코드 및 매장 위치 안내
  4. **간편 위젯 방식 (옵션):**
     ```html

       width="100%"
     ```

### 3.3 가맹점 공식 브랜드 프로필 (Merchant Brand Profile)
* **데이터 출처 (DB):** BestClub Firestore `merchants/{merchantId}` 문서
* **표출 내용:**
  * 상호명 (`merchantName` - 예: `BEST WINNER`)
  * 브랜드 로고 (`logoUrl`)
  * 대표자 이메일/성함 (`ownerEmail`, `ownerName`)
  * 매장 위치 및 주소 (`address`)
  * 고객센터 및 연락처 (`phone`)
  * 가맹점 보유 보너스 티켓 잔여량 (`btBalance` - 가맹점 신뢰도 지표)

### 3.4 이벤트 할인 쿠폰 & 교환 바우쳐 (Coupons & Vouchers)
* **데이터 출처 (DB):** BestClub Firestore `coupon_campaigns` 컬렉션
* **쿼리 조건:**
  ```javascript
  where("status", "==", "active"),
  where("applicableMerchantIds", "array-contains-any", [MY_MERCHANT_ID, "all"])
  ```
* **표출 내용:**
  * 가맹점에서 쓸 수 있는 활성 할인 쿠폰(10% 할인 등) 및 실물 바우쳐(식사권, 상품 교환권)
  * BM 가격 (0원이면 `[🎁 무료 발급]`, 10,000 BM 이상이면 `[💎 BM 구매]`)
  * 클릭 시 BestClub 로그인 계정으로 즉시 발급/구매되어 마이페이지 QR로 보관.

### 3.5 통합 회원 인증 및 BM 지갑 잔액 (Auth & Wallet Header)
* **데이터 출처 (Auth/DB):** Firebase Auth + `users/{uid}`
* **표출 내용 (헤더 우측 상단):**
  * **비로그인 시:** `[로그인 / 회원가입]` ➔ BestClub 통합 로그인 팝업 호출
  * **로그인 시:**
    * 회원 닉네임 / 이메일
    * **보유 BM 잔액:** `💎 {pointBalanceVnd.toLocaleString()} BM`
    * **보유 BT 잔액:** `🎟️ {btBalance} 장`
    * **보유 Point:** `⭐ {pointBalance.toLocaleString()} P`
    * 잔액 클릭 시 BestClub 지갑 충전 페이지로 즉시 이동.

### 4.4 웹메거진 실시간 컴포넌트 (`src/components/WebzineSection.jsx`)
```jsx
import React, { useState, useEffect } from "react";
import { db } from "../lib/firebase";
import { collection, query, where, onSnapshot } from "firebase/firestore";
import { MERCHANT_CONFIG } from "../config/merchant";

export default function WebzineSection() {
  const [articles, setArticles] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // BestClub webzine_articles 컬렉션 실시간 연동
    const q = query(
      collection(db, "webzine_articles"),
      where("status", "==", "published")
    );

    const unsubscribe = onSnapshot(q, (snapshot) => {
      const list = [];
      snapshot.forEach((doc) => {
        list.push({ id: doc.id, ...doc.data() });
      });
      // 해당 가맹점 관련 기사 우선 정렬
      list.sort((a, b) => {
        const aMatch = (a.merchantId === MERCHANT_CONFIG.merchantId) ? 1 : 0;
        const bMatch = (b.merchantId === MERCHANT_CONFIG.merchantId) ? 1 : 0;
        return bMatch - aMatch;
      });
      setArticles(list.slice(0, 4)); // 상위 4개 노출
      setLoading(false);
    }, (err) => {
      console.error("웹진 로드 실패:", err);
      setLoading(false);
    });

    return () => unsubscribe();
  }, []);

  if (loading) return null;

  return (
    <section className="webzine-section" style={{ padding: "50px 20px", background: "#f8fafc" }}>
      <div style={{ maxWidth: "1200px", margin: "0 auto" }}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "flex-end", marginBottom: "24px" }}>
          <div>
            <span style={{ fontSize: "0.85rem", fontWeight: "800", color: "#7c3aed", letterSpacing: "0.05em" }}>BESTCLUB WEBZINE</span>
            <h2 style={{ fontSize: "1.8rem", fontWeight: "800", color: "#0f172a", margin: "4px 0 0" }}>📰 {MERCHANT_CONFIG.brandName} 추천 스토리 &amp; 매거진</h2>
          </div>
          <a href="/megazine" style={{ color: "#7c3aed", fontWeight: "700", textDecoration: "none" }}>전체 매거진 보기 →</a>
        </div>

        <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fill, minmax(260px, 1fr))", gap: "20px" }}>
          {articles.map((art) => (
```

## 5. 가맹점 홈페이지 개발 AI 필수 10대 절대 원칙

1. **독립 DB / 로컬 스토리지 데이터베이스화 금지:**  
   가맹점 홈페이지용으로 독자적인 DB를 구축하거나 `localStorage`에 가짜 상품·기사를 영구 저장하지 마십시오. 모든 데이터는 `jumper-b15aa`에서 직접 실시간 쿼리합니다.
2. **상품 하드코딩 금지:**  
   HTML이나 JS 코드 안에 상품명, 사진, 가격을 정적으로 박아두지 마십시오. 반드시 `merchant_products`에서 실시간 쿼리하여 렌더링해야 합니다.
3. **'KM' 단어 영구 폐기 (BM으로 통일):**  
   모든 결제 및 잔액 표기는 **BM** 또는 **VND**로 표기합니다. 레거시 단어인 KM은 UI와 코드 어디에도 나타나선 안 됩니다.
4. **클라이언트 전달 단가 조작 방지:**  
   결제 시 클라이언트가 전달한 단가를 신뢰하지 말고, DB 상의 실제 `price` 필드를 기반으로 총액을 계산해야 합니다.
5. **BT 지급 규칙 엄수:**  
   **100,000 VND당 1 BT** 지급 로직(`Math.floor(amount / 100000)`)을 누락 없이 실행하여 고객에게 룰렛 기회를 보장해야 합니다.
6. **가맹점 테넌트 ID(`merchant_id`) 고정:**  
   모든 쿼리에는 해당 가맹점의 고유 ID(`merchant_id == MERCHANT_CONFIG.merchantId`)를 강제하여 타 가맹점 데이터가 노출되지 않도록 테넌트 격리를 유지합니다.
7. **BestClub 통합 계정 연동:**  
   가맹점 전용 회원가입 폼을 따로 만들지 말고, BestClub 통합 계정으로 로그인하여 즉시 보유 BM으로 결제할 수 있게 지원합니다.
8. **이벤트 쿠폰 적용 지원:**  
   BestClub에서 발행된 할인 쿠폰/바우쳐를 장바구니에서 조회하고 적용할 수 있도록 `user_coupons` 연동을 제공합니다.
9. **반응형 모바일 터치 최적화:**  
   스마트폰 브라우저에서도 장바구니 담기와 BM 1초 간편 결제가 원활하도록 모바일 최적화 UI를 구현합니다.
10. **웹진 연동 필수:**  
    가맹점 브랜드 신뢰도와 SEO, 고객 스토리 콘텐츠 유입을 위해 메인 페이지에 BestClub 웹진 위젯 또는 실시간 웹진 피드를 필수로 임베드합니다.

    ✨ 신규 이벤트 쿠폰 & 바우쳐 발행

    회원들에게 판매하거나 무료 지급, 또는 구글 리뷰 URL 댓글 확인 후 바우쳐 1장을 이체하는 이벤트를 등록합니다.

    💡 '구글 리뷰 인증 이벤트' 선택 시 회원이 댓글로 구글 리뷰 URL을 남기면 관리자가 확인 후 버튼 클릭 한 번으로 바우쳐 1장을 이체합니다. (1계정 1회 참여 자동 적용)
    * 회원들이 클릭하여 바로 구글 리뷰를 작성하러 갈 수 있는 매장 구글 지도 링크입니다.
    * 0 입력 시 '무료 발급' 상품으로 등록됩니다. (구글 리뷰 이벤트는 0 BM 고정)
    * 구글 리뷰 이벤트는 1계정 1회(1매)로 자동 고정됩니다.

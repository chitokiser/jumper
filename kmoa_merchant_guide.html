K-MOA Merchant API Guide

제휴 웹사이트(Zentaro, 반찬나라 등) 개발자를 위한 K-MOA 인증 및 결제 연동 가이드

🛠 연동을 위해 K-MOA 측에 요청해야 할 2가지

개발자는 연동을 시작하기 전, K-MOA 본사 운영팀으로부터 아래 정보를 발급받아 환경 변수에 등록해야 합니다.

  • Merchant ID (가맹점 고유 식별자): 결제 대금 정산의 기준이 되는 상점 고유 ID (예: store_zentaro_01)
  • Merchant API Secret: API 서버 간 통신 시 헤더에 담아야 하는 인증 암호 (예: Bearer sk_kmoa_...)

1. 아키텍처 개요 (No Web3)

K-MOA는 더 이상 복잡한 지갑 주소나 온체인 트랜잭션을 사용하지 않습니다. 모든 유저는 Firebase Auth의 고유 UID로 식별되며, 유저의 포인트 잔액 및 결제 트랜잭션은 100% Firebase Firestore 기반으로 실시간(0.1초 이내) 원자적 처리됩니다.

고객이 제휴 사이트에서 결제를 요청할 때, 아래의 REST API를 호출하여 고객의 UID와 차감할 금액(VND)을 전달하면 K-MOA 서버가 알아서 수수료 분배와 정산을 처리합니다.

2. REST API 레퍼런스

GET 회원 포인트 조회

유저의 UID를 쏴주면 현재 결제 가능한 K-MOA 포인트를 반환합니다.

https://us-central1-<PROJECT_ID>.cloudfunctions.net/api/v1/wallet/{uid}

요청 헤더 (Headers)

Authorization: Bearer <MERCHANT_API_SECRET>

응답 예시 (200 OK)

{
  "success": true,
  "data": {
    "uid": "firebase_uid_12345",
    "vndBalance": 500000,    // 베트남동 기준 충전(결제 가능) 잔액
    "kcaPoints": 1250        // 리워드 게임 포인트
  }
}
POST 가맹점 포인트 결제 승인

해당 UID 유저의 K-MOA 포인트 잔고에서 금액을 차감하고, 가맹점의 정산 대금표에 기록합니다.

https://us-central1-<PROJECT_ID>.cloudfunctions.net/api/v1/wallet/pay

요청 헤더 (Headers)

Authorization: Bearer <MERCHANT_API_SECRET>
Content-Type: application/json

요청 바디 (Request Body)

{
  "uid": "firebase_uid_12345",   // 결제를 요청한 유저 UID
  "merchantId": "store_zentaro_01", // 발급받은 가맹점 고유 ID
  "amount": 100000,              // 결제 금액 (VND 기준 숫자)
  "orderId": "your_order_88291"  // 제휴사 측 고유 주문 번호 (선택)
}

응답 예시 (200 OK)

{
  "success": true,
  "transactionId": "tx_abc123456",
  "receipt": {
    "paidAmount": 100000,
    "remainingBalance": 400000,
    "timestamp": "2026-09-01T20:30:00Z"
  }
}

3. 🚀 마케팅: 제휴사 추천인 자동 가입 링크

제휴 사이트 홈페이지에서 유저를 K-MOA로 보낼 때, 제휴사를 추천인(Mentor)으로 자동 등록시킬 수 있습니다. 고객이 아래 링크로 가입하면 즉시 보너스 포인트가 지급되며 가맹점과 강력하게 연동됩니다.

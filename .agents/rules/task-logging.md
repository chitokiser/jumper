# Task Logging Rule

## 규칙 설명
사용자가 요청한 작업이나 버그 수정, 기능 개발, 배포 등의 처리가 완료될 때마다 프로젝트 루트의 `TASK_LOG.md`에 처리 내역을 누적 기록합니다.

## 기록 항목
각 작업 완료 시 아래 양식으로 `TASK_LOG.md` 상단에 새 항목을 추가합니다:
```markdown
### [YYYY-MM-DD] 작업 제목

- **요청 일시**: YYYY-MM-DD HH:mm
- **요청 내용**: 사용자의 요구사항
- **원인 분석**: 문제 원인 또는 분석 내용
- **처리 내역**: 코드 및 로직 수정 내역
- **수정/추가 파일**: 변경된 파일 목록
- **검증 및 배포**: 테스트 결과 및 Git 배포 상태
```

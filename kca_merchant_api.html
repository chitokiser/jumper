KCA Merchant API

가맹점(외부 웹사이트)에서 KCA 회원 지갑 연동 및 Point 포인트/포인트 결제를 처리하기 위한 가이드

GET 유저 지갑 및 잔액 조회 (Wallet Info)

가맹점 웹사이트에 KCA 회원이 연동 로그인을 완료한 후, 해당 유저의 UID를 바탕으로 현재 KCA 포인트, VND 잔액, 그리고 연동된 온체인 지갑의 Point 포인트 잔액을 조회합니다.
https://us-central1-<PROJECT_ID>.cloudfunctions.net/api/v1/wallet/{uid}

헤더 (Headers)

Authorization: Bearer <MERCHANT_API_KEY>

응답 (Response) - 200 OK

{
  "success": true,
  "data": {
    "uid": "user_firebase_uid_1234",
    "kcaPoints": 12500,
    "vndBalance": 500000,
    "hexTokenBalance": "1500.00",
    "onChainWalletAddress": "0x1234abc..."
  }
}

POST 가맹점 결제 요청 (Payment / Point Token)

KCA 포인트나 Point 포인트을 사용하여 가맹점 웹사이트의 결제를 승인하고 차감하는 엔드포인트입니다. 결제 트랜잭션은 Firebase Cloud Functions를 통해 원자적(Atomic)으로 처리됩니다.
https://us-central1-<PROJECT_ID>.cloudfunctions.net/api/v1/wallet/pay

헤더 (Headers)

Authorization: Bearer <MERCHANT_API_KEY>
Content-Type: application/json

요청 본문 (Request Body)

{
  "uid": "user_firebase_uid_1234",
  "merchantId": "merchant_store_01",
  "currency": "Point", // 지원 통화: "Point", "POINT", "VND"
  "amount": 500,
  "orderId": "merchant_order_88219"
}

응답 (Response) - 200 OK

{
  "success": true,
  "transactionId": "tx_abc123456",
  "receipt": {
    "paidAmount": 500,
    "currency": "Point",
    "remainingBalance": "1000.00",
    "timestamp": "2026-09-01T15:20:00Z"
  }
}

⚠️ 가맹점 결제 수수료 안내 (Point / 포인트)

고객이 Point 포인트이나 KCA 포인트로 결제를 진행할 경우, 가맹점은 추후 정산 시 플랫폼 기본 수수료(Platform Fee, 기본 5~10% 내외)를 제한 금액을 정산받게 됩니다.

* 온체인 스마트 컨트랙트(DAO Vault)를 통해 직접 이체되는 Point의 경우 가스비(Gas) 외에 KCA DAO 정책에 따른 자동 수수료 차감이 발생할 수 있습니다.
* 오프체인(Firebase)에서 처리되는 포인트 결제는 정산일에 수수료가 일괄 공제됩니다.

💡 Backend Setup (개발자용)

위 API가 정상적으로 동작하려면 Firebase Cloud Functions 환경에 아래 코드를 추가하여 배포해야 합니다.

Cloud Functions (Node.js) 통합 소스 코드

// functions/handlers/merchantApi.js 의 예시 구조
const functions = require("firebase-functions");
const admin = require("firebase-admin");

exports.kcaMerchantApi = functions.https.onRequest(async (req, res) => {
  // CORS 처리
  res.set("Access-Control-Allow-Origin", "*");
  if (req.method === "OPTIONS") return res.status(204).send("");

  // 간이 API 키 검증 (가맹점 식별용)
  const authHeader = req.headers.authorization || "";
  if (!authHeader.startsWith("Bearer YOUR_SECRET_MERCHANT_KEY")) {
    return res.status(403).json({ success: false, error: "Unauthorized" });
  }

  // GET: 지갑 조회 로직
  if (req.method === "GET" && req.path.startsWith("/wallet/")) {
    const uid = req.path.split("/").pop();
    const db = admin.firestore();
    
    // KCA 포인트, 결제 대금 조회
    const kcbSnap = await db.collection("k_culture_balances").doc(uid).get();
    const pointBal = kcbSnap.exists ? kcbSnap.data().pointBalance || 0 : 0;
    const payBal = kcbSnap.exists ? kcbSnap.data().paymentBalanceVnd || 0 : 0;
    
    // Point 포인트 및 온체인 연동 지갑 정보 조회 (예시)
    const userSnap = await db.collection("users").doc(uid).get();
    const hexBal = userSnap.exists ? userSnap.data().hexBalance || 0 : 0;
    const wallet = userSnap.exists ? userSnap.data().walletAddress || null : null;

    return res.json({
      success: true,
      data: { uid, kcaPoints: pointBal, vndBalance: payBal, hexTokenBalance: hexBal, onChainWalletAddress: wallet }
    });
  }
  
  // POST: 결제 차감 로직 (Transaction 필요)
  if (req.method === "POST" && req.path === "/wallet/pay") {
    const { uid, merchantId, currency, amount } = req.body;
    // ... [Firestore 트랜잭션을 통한 포인트/Point 차감 및 가맹점 정산 테이블(merchant_settlements) 기록 로직]
    return res.json({ success: true, transactionId: "tx_mocked", receipt: { paidAmount: amount, currency } });
  }

  res.status(404).send("Not Found");
});

👥 가맹점 추천인 자동 연동 (신규 회원 유치)

가맹점의 홈페이지(웹사이트)를 통해 유입된 신규 고객이 KCA 플랫폼에 가입할 때, 가맹점의 지갑 주소가 추천인(Mentor)으로 자동 입력되게 하려면 회원가입 URL에 ?mentor= 파라미터를 추가하여 링크를 걸어주시면 됩니다.

홈페이지 삽입용 HTML 추천 가입 링크 예시

<!-- 가맹점의 이더리움(EVM) 지갑 주소가 0x123...abc 인 경우 -->
<a href="https://jump22.netlify.app/register.html?mentor=0x1234567890abcdef1234567890abcdef12345678" target="_blank">
  KCA 멤버십 가입하고 혜택 받기
</a>
위 링크를 타고 들어온 회원은 가입 시 "추천인 지갑주소" 칸이 자동으로 채워지며, 가입 완료 시 가맹점에게도 추천 보너스(동반 성장) 혜택이 지급될 수 있습니다.

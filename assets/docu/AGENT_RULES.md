# 에이전트(AI) 작업 원칙 및 메모 (AGENT_RULES.md)
이 파일은 프로젝트 작업 전 항상 숙지해야 할 중요한 컨벤션 및 요구사항을 기록합니다.

## 1. 언어 정책
* **모든 마크다운(.md) 파일(task.md, implementation_plan.md, 각종 설계 문서 등)은 반드시 한국어로 작성합니다.**
* 유저와의 커뮤니케이션 또한 한국어를 최우선으로 사용합니다.

## 2. 블록체인/온체인 기능 사용 절대 금지 (완전 제거)
* **어떤 경우에도 온체인(블록체인, Web3, ethers.js, 스마트 컨트랙트) 코드를 새로 작성하거나 유지해서는 안 됩니다. 기존의 온체인 코드는 발견하는 즉시 모두 걷어냅니다.**
* 사용자의 잔액(포인트/VND)은 Firestore를 통해 직접 관리하며, 모든 데이터는 순수 파이어베이스 환경에서 처리합니다.
* 유저 식별 및 추천인 코드는 지갑 주소(`wallet.address`)가 아닌 파이어베이스 고유 ID(`user.uid`)만을 사용합니다.

## 3. 잭팟/가맹점 수수료 분배 로직 (가맹점 결제 시)
* 가맹점 수수료율(feeBps)에 따른 수수료 중:
    - 20%: 추천인(멘토)
    - 10%: 추천인의 추천인(그랜드 멘토)
    - 30%: 잭팟 풀에 적립 (`jackpot_config/current`)
    - 40%: 플랫폼 수익 (추천인이 없을 경우 남는 지분도 플랫폼이 흡수)
